# Проектно-технологическая практика

## Курс «Программирование на основе классов и шаблонов»

**Проект:** графическое приложение для управления списком задач  
**Работа выполнена в паре:** Чернев Н. А. и Евсеев Д. М.

## О проекте

`TO-DO-List` — настольное приложение на C++ с графическим интерфейсом. Пользователь может добавлять задачи, редактировать их текст, отмечать выполненными, удалять ненужные записи и сохранять список между запусками программы.

## Возможности

- добавление новых задач;
- ввод и редактирование текста задачи;
- отметка задачи как выполненной;
- удаление задач;
- визуальная реакция элементов интерфейса на наведение мыши;
- сохранение статуса и текста задач в файл;
- загрузка ранее сохранённых задач при запуске.

## Стек технологий

- **C++17**;
- **SFML 2.6.x** — создание окна, отрисовка интерфейса, обработка мыши и клавиатуры;
- **CMake 3.16+** — конфигурация и сборка проекта;
- **`std::fstream`** — чтение и запись списка задач;
- **ООП:** классы `Button`, `CheckBox`, `TextBox`, `DataFile`, инкапсуляция состояния и разделение компонентов интерфейса;
- **ресурсы приложения:** шрифт Comfortaa и изображения состояний чекбокса.

## Сборка и запуск

Проект автоматически загружает SFML 2.6.x через CMake `FetchContent`, поэтому при первой конфигурации требуется подключение к интернету.

```bash
cmake -S . -B build
cmake --build build
```

После сборки запустите приложение из каталога проекта или настройте рабочий каталог так, чтобы программа могла найти папку `files`:

```bash
./build/bin/TO-DO-List
```

В Windows исполняемый файл будет расположен в каталоге `build/bin` с учётом выбранного генератора CMake.

## Использование

1. Запустите приложение.
2. Нажмите **Add new task**, чтобы добавить задачу.
3. Введите текст задачи и подтвердите его кнопкой **OK** или клавишей Enter.
4. Нажмите на чекбокс, чтобы отметить задачу выполненной.
5. Используйте кнопку **Del**, чтобы удалить задачу.
6. При закрытии приложения список автоматически сохраняется в `files/data.txt`.
